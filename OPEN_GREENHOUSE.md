BloomLogic
Extract all files into one folder. Open BloomLogic.exe. Keep _internal beside the executable. The lesson library opens first. Select If / Else, follow Observe and Understand, then Experiment and Challenge.
No Blender or Python installation is required for the packaged application. On launch failure, inspect %LOCALAPPDATA%\BloomLogic\startup-error.txt. Other lesson cards describe their intended exhibits.

Settings and experiment progress are stored locally. Resume returns to the paused experiment; Run begins a new simulation. Enter auto-indents; Tab inserts four spaces; Ctrl+Shift+Backspace clears the editor. If startup fails, see application.log and traceback.log beside startup-error.txt. Explicit optional graphics fallback: BloomLogic.exe --safe-graphics (lower-quality software renderer, not a guaranteed fix).

Clear and Example buttons are available above the editor. An invalid Run pauses the previous experiment without overwriting its state.
