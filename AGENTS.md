# BloomLogic | Living Python Encyclopedia
Effective 2026-11-26. This is the sole active product direction. No GTA-style game, player missions, quests, tasks, XP gates, driving, combat, or old Academy storyline. Build a standalone Python-first Windows interactive 3D encyclopedia of programming concepts. Learners observe real-world analogies, freely change inputs or code, replay, pause, scrub and compare outcomes. Teacher Dua is an optional realistic 3D narrator with voice, subtitles and authored gestures; never use primitive humanoids or illustrated substitutes. Python owns the application, curriculum, state, control execution and scene orchestration. Panda3D is the selected candidate renderer, Blender for editable assets. No browser shell, no paid AI API, no canned video masquerading as 3D.

Active phase: native BloomLogic library of fourteen exhibits, one playable greenhouse If/Else lesson only. Small, detailed botanical workbench, not a large map. Show seed imbibition, radicle emergence, branching roots in a physical cutaway/rhizobox, shoot emergence, leaf unfolding and later stress/wilting. Root and stem growth must extend along geometry over time; no whole-plant scale pop, clipping, floating seeds, or roots penetrating glass. Water falls from nozzle, meets substrate, darkens wet soil and stops when disabled; avoid claiming computational fluid dynamics. Time compression explicitly labeled. Lighting, wet/dry PBR, contact shadows, close-up depth, camera transitions and audio must be reviewed in actual runtime. User changes moisture/light/temperature and edits a finite Python if/elif/else controller; irrigation action is distinct from biology. Lack of light does not automatically kill seeds, and soil is not required for every plant system. Simplified model, not scientific predictive software. Explain branches, indentation, comparisons, equality and AND/OR. Optional practice and challenge, no compulsory gates. Provide guided narration and optional free exploration, reset and replay; show actual execution trace and errors.
