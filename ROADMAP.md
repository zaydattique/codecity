# Roadmap
G0 reset: remove obsolete game paths and instructions, preserve exact historical source and relevant asset pipeline. Core: deterministic state and bounded real Python conditional execution; tests for both paths and invalid inputs. G1 art: acquire exact licensed assets, model one workbench and cutaway; generate seed, root, stem, leaf, wilt, droplet and wetting animation with actual geometry; render macro frames and inspect clipping, continuity, contact, textures. G2 integration: Panda3D Python desktop, code editor, branch trace, environmental controls, compare, pause/reset/rewind, narration, sound and camera. G3 QA: real Windows package, offline test and 720p/1080p capture, hardware metrics, all controls; only then merge. No later lesson implementation before gate. Curriculum after demo: Print/comments, variables, data types, operators, if/else, for/range, break/continue, lists, tuples, sets, dictionaries, while, functions, strings. Each uses a distinct real-world exhibit, not a mission. Risks: visual assets and licensing, GPU, unverified packaging, educational model simplification. No fake controls or primitive final art.
