# Architecture
Python owns all runtime UI, deterministic fixed-day plant state and scene orchestration. codecity/model.py keeps immutable plant state; rules.py validates a finite AST grammar and executes actual CPython bytecode with no builtins and a single bounded callback. It is not a general sandbox. Invalid code must leave simulation unchanged. Rendering adapters consume state snapshots; no duplicate plant logic. Use Panda3D for runtime, Blender GLB for art. Future timeline caches immutable snapshots for rewind. Keep code trace and physical actions consistent. Model thresholds and days are illustrative, not species-calibrated. No Godot runtime dependency in the new application.
