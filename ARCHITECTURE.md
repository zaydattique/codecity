# Architecture
Native Python 3.13 owns navigation, curriculum, local progress, finite AST-validated CPython rule execution, fixed-day plant state, and rendering orchestration. Panda3D draws real 3D meshes; Blender creates their source. State drives visible geometry samples, irrigation, wetness and health color. The greenhouse lesson has Observe, Understand, Experiment and Challenge stages; the challenge evaluates six actual inputs. Starting-condition sliders apply only on Run; Pause resumes the same state, Reset starts at seed. No generic Python sandbox or botanical prediction claim. A local narration WAV per guide step is generated at build time. Offline Windows package contains its dependencies.

Native runtime also displays the exact licensed glTF potted plants and clay pot with verified per-file digests. Guide demonstration runs the same plant model as Experiment; Challenge executes six cases then animates a selected case. UI rendering uses a virtual 1280x720 viewport, with actual resized hit regions.
