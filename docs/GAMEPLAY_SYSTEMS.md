# Shared gameplay systems

The two modes use the same world/physics/animation/traffic/audio; separate profile progression and mode-scoped missions. The current session contract supports two stable protagonist IDs and independent in-memory progress per profile/mode, not a shipping save system. A world loader must activate a profile only after a real actor spawns. Future main menu, profile selection, continue and loading must only enable supported actions; use real threaded loading progress. The shared interaction helper validates distance and active-tree membership only; actual gameplay handlers must enforce visibility, permissions, reservations, animation and state. World authority remains in Godot. Harbor Boulevard first, with an actual interior suitable for both the story and Control Room mission. Full map/minimap use world-space lane graph, not a picture. No actual gameplay or maps yet. See sections 10–20 and 24 of master directive.
